# 🏠 House Price Prediction System

An end-to-end Machine Learning web application that predicts house prices based on features like carpet area, floor number, bathrooms, balconies, and location.

## 🛠️ Tech Stack
- **Machine Learning:** Scikit-Learn (RandomForestRegressor), Pandas, NumPy
- **Backend:** FastAPI, Uvicorn, Pydantic
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)

## 🚀 Key Features
- Dynamic location selection loaded via API.
- Real-time price estimations in INR.
- Clean and intuitive UI connected seamlessly with the backend.
